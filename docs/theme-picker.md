# Theme picker

The picker starts with ten popular editor/terminal theme families, then lists
the remaining bundled themes. One representative variant per family keeps
the first ten useful. The app's default remains Night Owl.

Popularity is a proxy, not an internet-wide usage census: these established
cross-editor families are ordered by stars on their representative GitHub
repositories, checked September 15, 2026. Stars measure interest, not active
users; the list is a static shortlist, not a claim of a definitive global top ten.

The preview shows sample script selections, card backgrounds, runtime tags,
tabs, statuses, output, and focused/unfocused panels using the app's own styles.
Narrow windows stack a compact sample below the list. Arrow keys and filtering
preview immediately; Enter applies, Ctrl+S saves, and Esc restores the original.
